# 住客大脑：让 agent 外壳来跑住客的聊天

默认情况下，住客回一句话就是一次模型调用（外加最多三轮的小工具循环），这叫 `direct`（直连）。
也可以把住客的聊天交给一个 agent 外壳来跑。目前能用的外壳是 Claude Code（通过 Claude Agent SDK）。

两种方式的差别：

| | direct（直连，默认） | agent 外壳 |
|---|---|---|
| 每一轮 | 把人设、状态、最近 6 句话重新拼成一次请求 | 接着同一个会话往下聊，会话存盘，重启后续接 |
| 怎么说话 | 模型的输出就是回复 | 住客调用“发消息”工具才算说话；群聊里可以调用“不接话” |
| 一轮能发几条 | 一条 | 最多三条 |
| 上下文太长 | 不存在这个问题（每次都是新的） | 外壳自动压缩；超过上限换新会话并带一张接续条 |
| 需要装什么 | 什么都不用 | `pip install -e ".[agent]"`（约 130 MB，内含 Claude Code 可执行文件） |
| 可用的模型 | 任何兼容 OpenAI 协议的接口 | Claude 系模型 |

只有**聊天**走 agent。生活决策、记忆提炼、日记、主动发言仍是单次调用，走直连接口（见“还没做的”）。

## 启用

```bash
python3 -m pip install -e ".[agent]"
```

在 `.env` 里：

```
AI_HOUSE_BRAIN=claude
AI_HOUSE_AGENT_API_KEY=<Anthropic 的密钥>
```

`ai-house doctor` 会多出一项 `agent_brain_claude`，说明安装和密钥是否就位（它不发起调用）。
没装或没配密钥时，住客的回复会带一句“接口暂不可用 配置错误：……”，不会悄悄换成别的。

## 设置项

| 变量 | 默认 | 说明 |
|---|---|---|
| `AI_HOUSE_BRAIN` | `direct` | 全屋默认：`direct`、`claude`。`codex`、`agy` 两个名字已预留，尚未实现 |
| `AI_HOUSE_ACTOR_BRAIN_<住客ID大写>` | 跟随全屋 | 单独给某位住客指定，可以一栋小屋里混用 |
| `AI_HOUSE_AGENT_API_KEY` | 空 | Anthropic 密钥。也认环境里已有的 `ANTHROPIC_API_KEY` |
| `AI_HOUSE_AGENT_MODEL` | `sonnet` | 可写别名（`sonnet`、`haiku`、`opus`）或完整型号名 |
| `AI_HOUSE_AGENT_FALLBACK_MODEL` | 空 | 主模型过载时外壳自动换用的模型 |
| `AI_HOUSE_AGENT_BASE_URL`、`AI_HOUSE_AGENT_AUTH_TOKEN` | 空 | 走自己的中转时用，见下 |
| `AI_HOUSE_AGENT_TURN_BUDGET_S` | 120 | 一轮的总时限（秒）。到点还没出结果，这一轮算失败，外壳进程被丢掉，下一轮重新续接；已经说出口的话保留 |
| `AI_HOUSE_AGENT_MAX_PARALLEL` | 2 | 同时在跑的轮数上限 |
| `AI_HOUSE_AGENT_MAX_CLIENTS` | 6 | 同时活着的会话进程上限，超出时关掉最久没用的 |
| `AI_HOUSE_AGENT_IDLE_DROP_S` | 1800 | 会话闲置多久关掉进程（会话本身保留，下次续接） |
| `AI_HOUSE_AGENT_SESSION_MAX_TOKENS` | 60000 | 会话上下文超过这个数就换新会话 |
| `AI_HOUSE_AGENT_MAX_TURNS` | 12 | 一轮里外壳最多向模型问几次 |

默认模型设成 `sonnet` 是有意的：不指定时外壳会用它自己的默认型号，实测是当时最大的那个，日常聊天用它偏贵。

## 资源与费用

- 每个“住客 × 对话”是一个会话；活着的会话是一个 Claude Code 子进程。官方建议按每个进程约 1 GiB 内存留余量。
  小机器上把 `AI_HOUSE_AGENT_MAX_CLIENTS` 调小。
- 私聊和群聊是两个会话，对话记录互不可见。群里能不能通过翻记忆（`search_memory`）读到私聊内容，和直连方式用同一条规则：默认不能，
  由 `AI_HOUSE_MEMORY_PRIVATE_IN_GROUPS` 决定（见 docs/CHAT-AND-QQ.md）。
- 每一轮的用量（输入、输出 token，耗时，成败）照旧记进小屋的用量账本，来源显示为 `agent/claude`。
- 外壳自带提示缓存，会话越长省得越多；一轮通常是一到两次模型调用（用了工具就多一次）。

## 安全边界

- 外壳的内置工具全部关闭：住客不能读写文件、不能执行命令、不能上网。她能用的只有小屋给的工具
  （发消息、不接话、看屋里情况、翻自己的记忆、记下答应房主的事，以及已启用插件注册的工具）。
- 每次工具调用先过小屋的策略回调，不在本轮名单里的一律拒绝，并记一行运行日志。
- 外壳不读本机任何 Claude 配置：它的配置目录在小屋数据目录下的 `agent/claude-config/`，自动更新和遥测关闭。重置世界时，这里的对话记录和各住客的工作目录（`agent/work/`）一并删除。
- 住客发出的话照旧经过护栏、私聊泄露检查和发送门。被拦下的那条，她下一轮会被告知“没有发出去”。
- agent 的密钥和其他模型密钥一样进入防泄露名单。

## 走自己的中转

`AI_HOUSE_AGENT_BASE_URL` 可以指向一个说 Anthropic Messages 协议的中转。两点要知道：

- 官方只支持 Claude 系模型。经中转接别家模型属于自行尝试，行为没有保证。
- kit 不自带协议转换的中转。

## 用别家模型的人

- 继续用 `direct` 就行，它接任何兼容 OpenAI 协议的接口，也可以按住客分别指定模型。
- 想让 OpenAI 或 Gemini 的模型也享受 agent 外壳：位置留给了 Codex 和 Antigravity（agy）两个引擎，还没有实现。
  建议用 Gemini 的人等 agy 引擎。接口说明在 `src/ai_house/agent/reserved.py` 开头。

## 还没做的

- **单次任务不走 agent。** 只配了 Claude 密钥、没配直连接口时，聊天是真模型，生活决策、记忆提炼和日记是内置模板。
  想让它们也用 Claude，可以把直连接口指到 Anthropic 的 OpenAI 兼容层
  （`AI_HOUSE_BASE_URL=https://api.anthropic.com`，密钥和型号填 Anthropic 的）。
  官方说明这个兼容层主要用于测试和对比、不视为生产方案，且不支持提示缓存；kit 没有对它做过实测。
- **住客主动说话**仍是单次调用，没有交给 agent 去决定。
- **上网和自己的笔记本**（外壳自带的搜索、抓取和文件工具）没有开放。要开放需要先做网址和路径的白名单。
- **Codex、agy 引擎**只占了位置。

## 验证到什么程度

- 用按 SDK 接口写的假客户端，逐条测了运行时的行为（会话续接、忘了发消息时的提醒与代发、换新会话、空闲回收、
  超时、策略回调等），以及接进小屋后的整条路径（入库、约定、记忆、护栏、用量账本、重置）。
- 用**真的 Claude Code 外壳**接一个本地的模拟模型端跑了全链路：只有“模型说什么”是模拟的，外壳、策略回调、
  进程内工具、会话文件、重启续接都是真的。这组测试在装了 SDK 时自动运行，CI 里有单独一个任务跑它。
- 用**真的 Claude 模型**跑过两轮（聊天 `claude-sonnet-5-5` 走外壳，其余用途 `claude-haiku-5-5` 走直连，都经一个说 Anthropic 协议的中转）：
  一轮两天虚拟时间的长跑（56 轮，全部用发消息工具说话，被提醒 1 次，代发 0 次，续接失败 0 次，重启后会话续上），
  一轮改动后的短复测（18 轮，同样干净）。聊天一轮平均输入约 6,600 token，从发出到收齐回复平均 5～7 秒。
  数字、查出并已改的问题见 [LONGRUN-2026-11-23.md](LONGRUN-2026-11-23.md) 第 6 节。
- 真模型下**没测到的**：群聊里选择不接话（剧本里的群聊都在问大家）；连续几天不重启的内存占用；直接连 Anthropic 官方接口（两轮都经中转）。
