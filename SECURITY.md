# 安全问题

如果你发现安全问题，或者在仓库里发现了不该公开的信息（密钥、账号、个人信息），
请不要开公开 issue，用 GitHub 的 Private vulnerability reporting（仓库的 Security 页面）私下报告。

# Security

Please report security issues, or anything in this repository that should not be public, privately
through GitHub's private vulnerability reporting on the repository's Security tab, not in a public issue.
